# V7 接口与运行说明

前端通过 Gateway 访问四个业务服务，内部接口仍受服务密钥、JWT 和当前账号状态校验。新增页面沿用 Vue 独立工程；后端仍为 Maven 父子模块、Eureka、Gateway、OpenFeign 与 MyBatis-Plus。

## 共教与交接

GET/PUT `/api/teacher/courses/{id}/team` 查看/委任；POST `/team/{userId}/remove` 移除；POST `/api/teacher/courses/{id}/transfer` 交接。写入携带 `expectedVersion`，交接另含 `targetId`、`retainPrevious` 与说明。目标须为本课当前启用协同教师；助教不能接任。主讲管理团队和课程发布/归档；协同教师编课、安排任务与批阅；助教批阅、学情与答疑，不能更改教学结构、成员和总评规则。历史作者不随交接改名。团队最多10位协作成员，变更名录展示最近200条。

## 文字题与学情

题型新增 `FILL_BLANK`、`SHORT_ANSWER`，二者均人工批阅；作答和参考答案最多4000字。开始作答冻结题目、参考答案、满分和知识点。含文字题的整卷 `gradingStatus=PENDING`，公开成绩为空，不能按零分结算。

GET `/api/teacher/practice-attempts/pending` 分页待办；GET `/api/teacher/practice-attempts/{id}` 批阅详情；PUT `/{id}/grade` 一次提交全部文字题，携带 `expectedVersion` 和逐项 `{id,score,comment}`。仅整数分且不超过题项满分；旧版本409；修订最多50次并留存历史。学生解析继续受尝试耗尽、截止或归档规则保护。温故册仅自动收录客观题，不把教师文字批阅当作客观答案校验。

GET `/api/teacher/courses/{id}/learning-insights?classId=...`：知识点分值加权、学舍对照、八周交卷记录和当前学习名册。数据上限500名学生、100学舍、200知识点；超过上限提示分课程管理。最近一份待批整卷不纳入该卷知识点统计，零分计入有成绩样本。关注条件为截止后缺交、已批练习均分率低于60%和14天无新增记录；待批另列，不作为低分证据。它是规则提示，不是AI判断。

## 迁移、备份与恢复

当前空库结构 `database/hanwen.sql` 为39表，已有V6先停止本项目并备份，然后执行 `scripts/Migrate-V7.ps1` 追加 V10/V11；该脚本也可重复执行V9。不得把空库初始化或演示快照覆盖现有教学库。完整备份含四库SQL和全部上传文件；密钥须单独保管。演示快照不含明文密码、活跃刷新会话和上传二进制，单靠公开SQL不能恢复媒体。

## 健康历史与本机发布

`python tools/monitor.py --gateway-port 8088` 单次检查并写 `.local/monitor` 的最新状态、历史与故障/恢复事件。相同持续故障不重复新增事件；超过5MB按文件轮转保留。外部通知未配置；Windows可手动用 `scripts/Check-Health.ps1`，Linux timer 配置为候选，远程未运行。

设置本机 `JAVA_HOME` 后，`python tools/release_local.py stage --module learning-service` 校验并保存现有构建JAR，返回槽位名称。`activate --slot 槽位名称` 仅替换相应模块的已核实项目进程，默认等待60秒健康；失败自动恢复之前JAR并等待90秒。课程服务同时处理本项目两个实例。槽位哈希、ZIP和迁移集合都必须匹配；迁移集合变化会拒绝自动回退。历史写 `.local/releases/history.jsonl`，备份与发布锁独立保留。

该工具只支持Windows本机应用工件，服务替换期间存在短暂不可用；未提供无停机发布。只允许数据结构兼容的应用版本，不能回滚数据库、迁移或历史数据。发布前须完整备份、确认业务兼容性。演练采用同一版本工件和1秒健康期限触发失败，不代表旧版本数据库降级已经验证。

## 重复验收

`scripts/Verify-V7-Api.ps1` 运行58项新接口和13项旧记录只读回归；加 `-IncludeStability` 创建独立课程进行24名学生、8线程并发和附件边界检查。测试会创建账号、消耗验收测验次数并保存附件，适用于本机私有验证环境。浏览器脚本见 `tests/browser/v7-platform.js`，必须注入全新私有测试账号；替换后的脚本和工具回显留在 `.local`，不可提交。

本轮并发在服务注册完成、一次只读预热后执行。初次并发曾出现依赖503，已调整答题远程校验与本地事务边界，增加不含凭证的依赖类别日志；当前重跑通过。健康UP不能替代业务请求验收。60秒读取和本机8线程不等于线上容量或长期稳定性承诺。

## 备份与物理回收

备份工具和服务回收任务共用上传目录中 `.hanwen-maintenance.lock` 的首字节排他锁。
备份从元数据核对到ZIP校验完成期间持锁，回收遇占用则跳过本轮；备份遇占用会明确失败，不生成成功记录。
锁文件不进入备份。进程退出后操作系统释放锁，文件仍可保留；不要通过删除该文件解除锁。
两个课程实例和作业服务必须指向同一个上传目录。启用新版回收前应同时部署新版备份工具。


## V12附件回收迁移

已有环境先备份 `hw_assignment`，再用具有 ALTER 权限的数据库连接执行
`database/migrations/V12__attachment_purge.sql`，完成后才重启新版本作业服务。
日常应用账号不应为此增加 DDL 权限。新建数据库使用更新后的分库脚本。
迁移会保留附件记录，为旧的已删除附件从升级时刻起算30天宽限期；不会立即清理这些文件。
清理任务每6小时运行一次，只删除超过宽限期的已删除附件；活跃附件和教学记录保留。


业务时间统一为北京时间，Java 使用 `BusinessTime`，页面使用 `utils/businessTime.ts`。
数据库连接继续显式设置 `+08:00` 会话时区；JDBC URL 中加号写为 `%2B`。

当前登录失败计数保存在单个 user-service 实例中，重启会清空。未经转发头信任配置时，
来自网关的请求共用连接地址，因此同名账号共用五次失败、五分钟限制。不能直接信任客户端传入的
`X-Forwarded-For`。恢复真实客户端地址必须结合 nginx 覆盖写入、网关信任判断和实际代理链验收。
