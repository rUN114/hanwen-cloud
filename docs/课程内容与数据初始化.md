# 课程内容与数据初始化

阅读课程的可维护原稿保存在 `database/content/courses.json` 和 `database/content/works.json`。前者组织课程、章节、练习与习作，后者记录古代原文、来源、版本、词义和参考译意。修改内容应先修改原稿，再核对当前教学环境，不能用一次初始化覆盖已投入使用的课程。

## 内容范围

| 阅读方向 | 章节主题 | 主要作者或篇目 |
| --- | --- | --- |
| 唐诗研读 | 月色与春声、雨后山居、城春与家书、登临与送别 | 李白、孟浩然、王维、杜甫 |
| 宋词研读 | 时间回环、怀人与祝愿、雨中徐行、重复与声情 | 晏殊、苏轼、李清照 |
| 古典散文 | 物与志、夜游、空间叙事、忧与乐 | 刘禹锡、周敦颐、苏轼、陶渊明、范仲淹 |
| 经典阅读 | 重章、追寻、学习自省、日常与心境 | 《诗经》《论语》《饮酒·其五》 |
| 阅读写作 | 提问、引用分析、段落职责、证据修订 | 以已收录诗文练习赏析 |
| 汉文化专题 | 元日、行衣、雪夜小舟、剑与号角 | 王安石、孟郊、张岱、辛弃疾等 |

六门课程各四章，共24章。每章配置一题单选与一题简答，单选40分、简答60分，合计100分；简答须人工批阅，每份练习最多尝试三次。每课提供两项习作及一份可下载的完整学习导引。自主研读课程不设统一截止日期，教师可按实际班级安排另行设定。

习作按文本依据35分、分析论证35分、结构表达20分、来源版本10分设置评分项。此处是评分标准，没有预设任何学生得分。导入也不生成学生、选课、学习进度、收藏、札记、答卷、评语或答疑。班级初始化为空，学生和教师在实际使用中建立教学记录。

## 空环境安装

1. 按 README 初始化四个业务库与私有运行配置，先备妥管理员账号。
2. 通过管理员建立 `lincheng` 与 `shenyan` 两个教学账号，确认均为启用的教师。内容目录明确使用这两个账号管理课程，导入工具不代建账号或设置密码。
3. 停止业务服务，准备私有 MySQL 客户端配置文件，包含数据库管理连接。不要将该文件加入 Git。
4. 先检查内容并生成待审阅 SQL，再在确认教学环境为空时导入。

```text
python tools/install_academy_content.py --validate
python tools/install_academy_content.py --sql-out .local/academy-import.sql
python tools/install_academy_content.py --apply --client-file .local/mysql-client.ini --mysql-dir "C:/Program Files/MySQL/MySQL Server 9.7/bin" --storage .local/uploads
```

导入前检查课程、题库和习作是否为空，书库只允许空库或最初随结构提供的四篇古文。已有其他教学内容时直接拒绝，工具没有清空、覆盖或强制选项。现有数据的整理需要单独审查，先保存数据库与上传文件备份，再按已确认记录处理。

SQL 在一个事务中写入四库，保留外键检查；失败时由数据库回滚。本次新写入的导引文件在 SQL 失败时清理，原有上传文件保留。成功后写入私有 `.local/academy-content.json` 标记，防止再次把写入型测试放到当前教学环境。

## 日常教学与回归测试

学生首次登录后从课程广场查看介绍并加入，实际阅读后标记完成，答卷、习作与评语随学习和批阅形成。没有完成或没有交卷时，页面应如实显示零值与下一步入口。

旧的真实 API 验收、恢复和压测脚本会建立测试数据。它们的公共入口调用 `tests/fixture_guard.py`，检测到阅读内容标记就停止。应使用独立检出、独立运行配置和隔离的 MySQL 实例进行写入测试；不能复制正在使用的数据库配置后仅删除标记。

不写业务数据的检查可直接运行：

```text
python tools/install_academy_content.py --validate
python tests/content_catalog_test.py
npm run format:check --prefix frontend
npm run build --prefix frontend
```

## 原文与编写说明

古代原文按各条记录的维基文库文本整理，转为简体并调整教学阅读标点；不同版本的字词按各篇说明保留。《桃花源记》《岳阳楼记》仅收录明确标识的节选，《论语·学而》收录三条选章。讨论全篇结构时，课程要求回到来源页补读全文。

每篇正文、版本与链接在书库详情、章节原文以及下载导引中一并展示。译意、词义提示、导读、问题和评分参考由本项目编写，没有搬用来源站点的现代译文与赏析。书院导读允许讨论与修正，不以唯一解析限制有依据的阅读。
