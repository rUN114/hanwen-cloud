# Git 与 GitHub 使用

公开仓库：https://github.com/rUN114/hanwen-cloud 。桌面项目目录即本地 Git 工作目录。

每次大更新按以下顺序执行：完成代码与文档；运行相关构建及检查；审查 diff 和上传边界；提交；推送；确认 GitHub 上的提交与本地一致，并检查 Actions 结果。大版本里程碑再创建版本标签和 Release。

```text
git status
git diff
git add <本次需要提交的文件>
python tools/check_publication.py
git diff --cached --stat
git commit -m "feat: 用具体行为描述更新"
git push
```

首次 Git 快照为 v7.1.0。它包含此前已开发的完整源码，不表示过往版本有逐次 Git 历史。

公开仓库不包含 `.local`、密钥、密码、数据库数据快照、教学上传文件、原始录像和个人课程材料。它们留在电脑上，GitHub 源码备份不能代替数据库及上传目录的私有备份。公开文档只保留运行接口、素材来源和版本说明。

`tools/check_publication.py` 检查当前 Git 索引里的内容，包括忽略目录误提交、私钥及令牌模式、本机已知凭据和个人信息。检查通过只是一次提交内容检查，不保证程序不存在所有安全问题。

工作流只自动执行源码检查、构建与单元检查；真实 MySQL、服务联调及浏览器验收另行运行。推送后若远端失败，应修复、复验并继续提交，不删除失败历史。
